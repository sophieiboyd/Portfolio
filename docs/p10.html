Portfolio 10: Summer Workflow

Overview:

Goal:

In my last portfolio piece, I focused on what I would do with my free time this summer. For this piece, I will turn my attention to my outstanding projects that I hope to complete or push forward by the end of the summer. My goal is to create a graphic organizer to help me break the projects down into smaller tasks and keep track of my progress.

Data:

No dataset for this one- I will just be entering a list of my projects/tasks.

I am going to start by searching online for recommended packages/tools for creating graphic organizers and/or flow charts to test out.

Options include:

  • DiagrammeR
library(DiagrammeR)

Some starter code to see how it works:

DiagrammeR("graph LR;
           A --> B;
           B --> C;
           B --> D")
DiagrammeR("graph TB;
           A --> B;
           B --> C;
           B --> D")

Based on how the levels work/look, I think it would make sense to make a separate organizer for each project I am working on. I will start with the remaining tasks for my FYP:

DiagrammeR("graph TB;

           FYP --> Writing;
           Data --> Cleaning;
           Data --> Analysis;
           Writing --> Results;
           Writing --> Discussion")
DiagrammeR("graph TB;
