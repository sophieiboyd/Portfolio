Portfolio 10: Summer Workflow

Overview:

Goal:

In my last portfolio piece, I focused on what I would do with my free time this summer. For this piece, I will turn my attention to my outstanding projects that I hope to complete or push forward by the end of the summer. My goal is to create a graphic organizer to help me break the projects down into smaller tasks and keep track of my progress.

Data:

No dataset for this one- I will just be entering a list of my projects/tasks.

Product:

A series of diagrams breaking down the tasks I hope to complete this summer, organized by project and by month.

Interpretation:

DiagrammeR was easy to use and created pretty nice visualizations, but the results were a bit simpler than I had hoped. I think it is a good starting point for creating general timelines.

Sources:

https://sites.temple.edu/psmgis/2017/07/30/flow-charts-in-r-using-diagrammer/

https://rich-iannone.github.io/DiagrammeR/#

https://graphviz.org/docs/attrs/rankdir/

I started by searching online for recommended packages/tools for creating graphic organizers and/or flow charts to test out. The only option that seemed to fit my goals was DiagrammeR.

Loading DiagrammeR

library(DiagrammeR)

Some starter code to see how it works:

DiagrammeR("graph LR;
           A --> B;
           B --> C;
           B --> D")
DiagrammeR("graph TB;
           A --> B;
           B --> C;
           B --> D")

Based on how the levels work/look, I think it would make sense to make a separate organizer for each project I am working on.

Remaining tasks for my FYP:

DiagrammeR("graph TB;
           FYP --> Data;
           FYP --> Writing;
           Data --> Cleaning;
           Data --> Analysis;
           Writing --> Results;
           Writing --> Discussion")

Remaining tasks for a project that I am assisting with:

DiagrammeR("graph TB;
           NP --> Writing;
           Writing --> Results3;
           Writing --> Results4")

Remaining tasks for another project that I am assisting with:

DiagrammeR("graph TB;
           PAC --> Data;
           PAC --> Writing;
           Data --> Cleaning;
           Data --> Analysis;
           Writing --> Introduction;
           Writing --> Discussion")

Finally, the remaining tasks for turning my thesis into a manuscript to submit for publication:

DiagrammeR("graph TB;
           Thesis --> Planning;
           Thesis --> Data;
           Thesis --> Writing;
           Planning --> Meeting;
           Planning --> Change_groups;
           Data --> Cleaning;
           Data --> Analysis;
           Writing --> Edit_intro;

Now that I have the basic layout of tasks that need to be completed, I want to add some sort of timeline element to the diagrams. I am going to try to color code the boxes by month to reflect when I would like each task completed:

grViz("digraph {
graph [rankdir = LR]
node [shape = rectangle, style = filled]

May [fillcolor = yellow]
June [fillcolor = green]
July [fillcolor = cyan]
August [fillcolor = purple]

May -> June [color = black];
June -> July [color = black];
July -> August [color = black]

}")
