Portfolio 6: Simulating Parenting and Civic Engagement Data

Overview:

Goal:

I want to use my portfolio to share some of the analytic work I did for my Master’s thesis. However, I need to keep my data private. My goal for this piece is to simulate a dataset that resembles my thesis data. I plan to use this simulated dataset in future portfolio pieces.

Data:

My original dataset contained youth-reported measures of parenting practices, civic engagement, and demographic information collected over three waves of a longitudinal study (labeled here as Times 1-3). Participants made up 11 different cultural/geographic groups, which were represented by effect-coded predictors in my final regression models. There was quite a bit of missing data across waves, so to simplify my simulation, I will use the most restricted subsample I had (668 participants).

Specific core variables include:

  • Joint decision making at Time 1 (JDM; a measure of moderate support for autonomy)
  • Independent decision making at Time 1 (IDM; a measure of extreme support for autonomy)
  • Maternal warmth at Time 1 (MatWarmth)
  • Paternal warmth at Time 1 (PatWarmth)
  • Civic engagement at Time 2 (CE_2)
  • Civic engagement at Time 3 (CE_3)

Recruitment groups include:

  • Naples, Italy
  • Rome, Italy
  • Kenya
  • Philippines
  • Thailand
  • Sweden
  • US, African American
  • US, European American
  • US, Hispanic
  • Colombia
  • Jordan

Product:

A simulated dataset containing all variables necessary for the analyses I completed for my thesis. (I obtained all parameter values by running descriptive and correlational analyses with the original dataset in SPSS.)

Simulating the central variables

set.seed(123)

n_participants <- 668

var_names <- c("JDM", "IDM", "MatWarmth", "PatWarmth", "CE_2", "CE_3")

mean_vars <- c(.96, .26, 3.46, 3.26, 2.04, 1.81)
sd_vars <- c(.40, .21, .56, .74, .86, .80)

cor_matrix_parenting_CE <- matrix(
  c(
1.0000, -.802, .129, .172, .086, .103, 
-.802, 1.0000, -.148, -.197, -.129, -.102,
.129, -.148, 1.0000, .551, .056, -.002,
.172, -.197, .551, 1.0000, .046, .044,
.086, -.129, .056, .046, 1.0000, .521,
.103, -.102, -.002, .044, .521, 1.000
  ),
  nrow = 6, ncol = 6, byrow = TRUE,
  dimnames = list(
c("JDM", "IDM", "MatWarmth", "PatWarmth", "CE_2", "CE_3"),
c("JDM", "IDM", "MatWarmth", "PatWarmth", "CE_2", "CE_3")
  )
)

cov_matrix_parenting_CE <- cor_matrix_parenting_CE * (sd_vars %*% t(sd_vars))

parenting_CE_data <- mvrnorm(n = 668, mu = mean_vars, Sigma = cov_matrix_parenting_CE)

df_civicengagement <- cbind(df_civicengagement, parenting_CE_data)
