Portfolio 7: Regression Models and Tables with Simulated Data

Overview:

Goal:

In my last portfolio piece, I simulated a dataset based on the data that I used to complete my thesis. Now, I want to replicate some of my analyses with the simulated data to show my work. My analyses consisted of a long series of regression models predicting future civic engagement from perceived parenting during adolescence. I reported the results with a series of tables that I (painstakingly) created by hand. To save myself time with this kind of reporting in the future, I want to learn how to create APA style regression tables in R. In addition to actually running the regressions with my simulated data, my goal for this piece is to find the best method for producing clean tables that I can use in my future work.

Data:

I simulated my data in my previous portfolio piece. The core variables are listed below. Additionally, demographic variables include age, gender, and maximum level of parental education (used as a proxy for SES).

Specific core variables include:

  • Joint decision making at Time 1 (JDM; a measure of moderate support for autonomy)
  • Independent decision making at Time 1 (IDM; a measure of extreme support for autonomy)
  • Maternal warmth at Time 1 (MatWarmth)
  • Paternal warmth at Time 1 (PatWarmth)
  • Civic engagement at Time 2 (CE_2)
  • Civic engagement at Time 3 (CE_3)

Recruitment groups include:

  • Naples, Italy
  • Rome, Italy
  • Kenya
  • Philippines
  • Thailand
  • Sweden
  • US: African American
  • US: European American
  • US: Hispanic
  • Colombia
  • Jordan

Product:

A series of regression models presented with APA style tables created in R.

Data cleaning

Before I can run my regression models, I need to mean-center my predictors and dummy-code gender:

civicengagement_data <- civicengagement_data %>%
  mutate(JDM_cent = JDM - .95) %>%
  mutate(IDM_cent = IDM - .26) %>%
  mutate(MatWarmth_cent = MatWarmth - 3.46) %>%
  mutate(PatWarmth_cent = PatWarmth - 3.24) %>%
  mutate(CE_2_cent = CE_2 - 2.03) %>%
  mutate(dummy_male = case_when(
    male == "not male" ~ 0,
    male == "male" ~ 1
  ))
